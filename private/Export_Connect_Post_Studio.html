1Find an idea

Stuck for a topic? Get ideas built from your constraints, browse the latest findings, or add an article or document. Or skip this and write your own topic in step 2.

The latest findings Claude has gathered, newest first, in six groups: trade policy, food and beverage trends, trade show lead-ups, engaging topics, FMCG news and domestic retail trends. Every finding is used when your post is written. Copy Prompt for New Library copies a request you paste into a Claude chat: Claude searches articles published in the last two weeks across the six groups and saves 5 to 10 of them here, each with a suggested post idea. Only findings from the last 2 weeks, counted from today, are ever shown; older ones drop off automatically. They appear on their own as they are saved, usually within 10 to 20 minutes.

Connecting to the saved library…

Add an article, case study or write-up and it becomes a fresh post brief built only from it, replacing the current topic and notes. It is also saved under Latest findings. Upload a PDF, Word, Excel or text file, or paste the key text. If you downloaded the file from a web page, put that page in the links box as a reference. This page cannot open other websites itself, so links are saved as references unless you press Read these links in Claude, which asks Claude to read them and send back one combined write-up. The file itself is not kept; only its text is read.

Add External Resource(s)

Attach supporting data such as PDFs, Word or Excel files. Claude reads each one and keeps a short write-up of the facts you can use. The files are not saved, only the write-ups, so you can tick them again for later posts. Ticked write-ups are used as supporting data in your next post or brief.

      Posting on LinkedIn

      1. Check the preview. The slides on the Slides tab are exactly what gets exported. Edit text, theme, size, cover photo and partner logo there.
      2. Download the carousel. Use the PDF to post as a LinkedIn document carousel. Use the PNG zip if you need each slide as an image, for example for Instagram.
      3. Post it. Start a LinkedIn post, add a document, upload the PDF, give it a title, then paste the caption (Copy caption above).
